The two detectors

robust_z — deterministic, fully traceable (the default).
Baseline = the same weekday + hour-of-day over the trailing 3 weeks (a "like-for-like" comparison). It takes the median of those points as expected, measures spread with MAD, and reports a robust z-score. Every number comes straight from a logged SQL query.
seasonal_ml — unsupervised, hand-rolled. No trained ML library, no saved weights.
It builds a seasonal profile: the median of every (weekday, hour-of-day) bucket across all history — that table of medians is the model, rebuilt each call (pandas only). It then scores the target hour's residual (actual − seasonal) against the spread of all residuals. Because it pools the whole history, its noise estimate is far more stable than robust_z's 3-point one — so it fires less on tiny moves.
isolation_forest — an actual trained ML model (scikit-learn IsolationForest), unsupervised.
Fits a forest on all historical hours and scores how easily the target hour is "isolated" (outliers isolate faster → higher anomaly score). Two feature modes, toggled by the IF features dropdown:
  • univariate — features are [value, seasonal, residual, hour, weekday] for the chosen metric; flags when the forest isolates it and the metric moved ≥ its pct floor.
  • multivariate — features are the whole ratio vector [fill_rate, render_rate, ctr, ecpm, rpr, requests]; flags hours whose combination of metrics is unusual, even if the single metric looks normal.
Deterministic (fixed random_state); the feature-pull SQL is logged for traceability.

Buzzword decoder

medianThe middle value — unlike an average, one huge outlier can't drag it around.
MADMedian Absolute Deviation — a robust "how spread out is the data" measure (the median of the distances from the median).
robust z-score(value − center) ÷ (MAD × scale). Like a normal z-score but built from median/MAD, so outliers don't distort it.
like-for-like baselineComparing an hour only to the same weekday + hour in prior weeks — apples to apples, so weekly/daily seasonality doesn't look like an anomaly.
seasonal profileThe "normal" value for each weekday×hour slot, learned from history.
residualWhat's left after subtracting the expected/seasonal value — the part a model didn't predict.
unsupervisedLearns "normal" from the data itself with no labelled examples of anomalies.
traceabilityEvery number can be reproduced from a named SQL query — so a judge (or you) can verify it.
